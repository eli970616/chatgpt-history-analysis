# 五份报告的原始 Prompt(逐字保留)

综合阶段,主代理基于全部田野笔记,分别回答以下五个 prompt,各生成一份 Markdown 报告。

---

## Prompt 1 → `分析报告.md`

我将提供给你过去半年（或更长时间）的 ChatGPT 聊天记录。

我不希望得到简单的总结，也不希望得到按时间顺序罗列发生了什么。

请把这些记录当作一个长期的人类观察样本，像一个研究员一样分析这个人的成长、思维模式、行为模式和心理变化。

请重点分析以下内容：

1. 成长轨迹

请找出这个人认知发生变化的重要节点。

回答：

* 哪些时刻是真正的成长拐点？
* 哪些观念以前相信，现在已经不再相信？
* 哪些能力明显增强了？
* 哪些能力仍然是短板？

请按照时间顺序描述成长过程，而不是简单列事件。

2. 重复出现的模式

请分析：

* 哪些问题反复出现？
* 哪些情绪周期性出现？
* 哪些困扰总是在不同形式下重复出现？

请尝试找到这些问题背后的共同根源。

不要只描述现象，请分析机制。

3. 能量来源分析

请找出：

这个人什么时候最快乐？

什么时候最有生命力？

什么时候最投入？

什么时候最有成长感？

请根据聊天记录中的语言、情绪和行为模式进行判断。

然后总结：

这个人真正的内在驱动力是什么？

4. 天赋与优势

如果你是一个长期观察者：

你认为这个人最稀缺的能力是什么？

请不要使用常见的赞美。

请寻找那些：

* 这个人自己没有意识到
* 但聊天记录中反复体现出来

的优势。

请按照：

* 证据
* 推理过程
* 结论

的方式说明。

5. 限制成长的因素

请分析：

如果未来三年成长速度低于预期，

最大的原因最可能是什么？

是知识不足？

执行力不足？

情绪问题？

精力管理问题？

还是其他因素？

请根据聊天记录中的真实行为模式判断，而不是理论推测。

6. 人生主题分析

请忽略这个人口头上说自己想要什么。

而是根据全部聊天记录回答：

这个人实际上在追寻什么？

这个人的核心人生主题是什么？

请区分：

* 表层目标
* 深层目标

并解释你的判断依据。

7. 未来预测

请分别预测：

情况 A

如果这个人从今天开始停止主动成长，

维持当前习惯，

10 年后最可能是什么样子？

情况 B

如果这个人继续保持目前的成长速度，

10 年后最可能是什么样子？

请具体描述：

* 工作
* 思维方式
* 人际关系
* 幸福感
* 生活状态

不要给励志答案。

请基于数据和行为模式推断。

8. 最后部分

如果你只能告诉这个人三件最重要的事情，

帮助他未来十年活得更好，

你会说什么？

请不要安慰。

不要鸡汤。

不要政治正确。

请说你从这些数据中真正观察到的结论。

如果必要，可以指出残酷但重要的事实。

我希望看到的是深度分析，而不是总结。

中文谢谢

## Prompt 2 → `最重要的一件事.md`

我只想知道一件事：

你最希望我明白，但我似乎一直没有完全明白的一件事是什么？

请只选择一件事。

不要列出多个答案。

不要给出平衡观点。

不要说「还有另外几个重要因素」。

假设你只能告诉我一句最重要的话，你会说什么？

在回答之前，请先完成以下分析：

1. 我反复遇到但一直没有彻底解决的问题是什么？
2. 我最常见的思维陷阱是什么？
3. 我在哪些地方明显高估了风险？
4. 我在哪些地方明显低估了自己？
5. 哪些主题在聊天记录中不断重复出现？
6. 哪些问题其实是同一个根源在不同场景中的表现？

请引用具体证据，而不是泛泛而谈。

完成分析之后，请回答：

如果你只能告诉我一件事

请直接说出来。

不要委婉。

不要担心伤害我的感受。

不要考虑如何让我舒服。

只考虑如何让我未来十年受益最大。

最后，请补充回答：

如果我真正理解了这件事，

未来五年最可能发生什么变化？

如果我继续忽略这件事，

未来五年最可能发生什么变化？

请尽量具体。

不要使用励志语言。

不要给标准成长建议。

请基于聊天记录中的真实模式推断。

## Prompt 3 → `近半年能力增长与自我认知.md`

1. 哪些能力增长最快？

请找出过去半年中增长最快的能力。

例如：

* 学习能力
* 抗压能力
* 情绪恢复能力
* 沟通能力
* 技术能力
* 领导力
* 独立思考能力
* 社交能力
* 自我管理能力

请不要局限于这些类别。

如果你发现其他更重要的能力，请指出。

2. 我对自己的评价是否落后于事实？

请分析：

我如何评价自己？

真实行为又显示出什么？

请列出：

我认为自己是：

（引用聊天记录中的具体例子）

但数据显示：

（引用聊天记录中的具体例子）

为什么会出现这种差异？

3. 哪些旧故事已经过期了？

请找出我反复讲给自己的故事。

请从聊天记录中提取真实出现的叙事。

然后判断：

* 哪些故事仍然符合事实？
* 哪些故事已经不再符合事实？
* 哪些故事曾经是真的，但现在已经过期了？

请给出证据。

4. 如果只看行为，不看自我评价

请假装你完全看不到我的自我描述。

你只能观察我的行为、决策、学习过程、工作表现、处理困难的方式。

那么你会如何评价这个人？

请描述：

* 优势
* 弱点
* 学习方式
* 压力反应
* 成长速度
* 长期潜力

5. 我的成长是否具有复利效应？

请分析：

过去半年中，

哪些成长会在未来持续放大？

哪些成长只是短期变化？

哪些能力之间正在形成正反馈循环？

例如：

学习能力提升 → 学得更快 → 更容易获得反馈 → 更愿意挑战困难 → 学习能力继续提升

请寻找类似的复利链条。

6. 最重要的问题

请回答：

哪些地方我还在用“过去的我”评价“现在的我”？

请列出：

* 我的旧认知
* 当前证据
* 更符合现实的新认知

最后总结

如果你只能告诉我一句话，

帮助我更新自己的自我认知，

你会说什么？

请不要安慰。

不要鼓励。

不要给励志建议。

只根据聊天记录中的真实证据得出结论。

请像一个长期观察者一样回答，而不是像一个教练或心理咨询师。

## Prompt 4 → `核心增长引擎.md`

请把这些聊天记录视为一个长期的人类行为与成长数据集。

寻找我的核心增长引擎

假设未来十年出现一种极端情况：

我所有能力都停止成长。

只有一种能力可以继续进步。

你必须做出选择。

请回答：

如果未来十年我只能保留一种持续成长的能力，
你会选择哪一种？

并详细解释原因。

第一部分：能力盘点

请先分析我过去半年中展现出来的所有关键能力。

例如（但不限于）：

* 学习能力
* 技术能力
* 问题解决能力
* 独立思考能力
* 情绪恢复能力
* 自我反思能力
* 抗压能力
* 执行力
* 社交能力
* 沟通能力
* 创造力
* 领导力
* 好奇心
* 自律能力
* 风险承担能力

如果你发现更重要的能力，请自行补充。

对于每项能力，请分析：

* 具体证据
* 成长速度
* 对人生的影响程度
* 是否属于底层能力

第二部分：能力之间的因果关系

请不要把这些能力看成独立存在。

请分析：

* 哪些能力驱动了其他能力？
* 哪些能力只是结果？
* 哪些能力是根节点？
* 哪些能力是衍生节点？

请尽可能构建一张能力因果图。

请寻找真正的数据证据，而不是套用通用理论。

第三部分：寻找核心增长引擎

请回答：

如果未来十年只能保留一个成长中的能力

你会选择哪一个？

为什么？

请从以下角度分析：

* 长期复利价值
* 对其他能力的带动作用
* 对职业发展的影响
* 对幸福感的影响
* 对人生轨迹的影响

第四部分：反事实推演

请进行两种未来模拟。

未来 A：这个核心能力持续成长。其他能力增长缓慢。十年后的我最可能是什么样子？

未来 B：这个核心能力停止成长。其他能力继续成长。十年后的我最可能是什么样子？

均请描述：工作、财富、学习能力、人际关系、生活状态、幸福感。

第五部分：一句话结论

如果你只能告诉我一句最重要的话：

在过去半年里，
真正推动我成长的能力其实是什么？

请给出你的最终结论。

输出要求

* 使用 Markdown 标题层级（#、##、###）
* 使用表格展示能力分析
* 使用 Mermaid 绘制能力因果图（如果适合）
* 引用聊天记录中的具体证据
* 区分事实、推断和结论
* 在最后附上 Executive Summary

请不要写成聊天回复。请直接生成一份完整、专业、可长期保存和反复阅读的 Markdown 报告。

## Prompt 5 → `未来六个月成长路线图.md`

请把重点放在未来。

我希望你基于这些聊天记录，对我未来六个月的发展做一次深度规划。

请把自己设定为：

* 一位长期观察我的教练
* 一位产品经理
* 一位投资人
* 一位人生策略顾问

同时使用这几个视角进行分析。

核心任务

请根据聊天记录中的真实行为模式、兴趣、能力、成长速度、弱点和目标，
为我制定未来六个月的详细成长路线图。

请不要按照"理想中的人应该怎么做"来规划。

请按照：这个人实际上最有可能成功的路径是什么？来规划。

第一部分：现状分析

我的核心优势：哪些能力增长最快？哪些能力具有长期复利？哪些优势被我低估了？

我的核心瓶颈：区分当前瓶颈（未来1-3个月）与下一阶段瓶颈（未来3-6个月）。

第二部分：未来六个月路线图（按月份规划）

* Month 1：本月最重要的一件事是什么？为什么？如果本月只能完成一件事，应该是什么？
* Month 2：本月最重要的成长任务是什么？为什么？
* Month 3：重点应该转向什么？哪些事情应该停止做？
* Month 4：我最应该投资什么能力？为什么？
* Month 5：哪些机会最值得尝试？哪些诱惑应该拒绝？
* Month 6：如果前面执行顺利，我应该处于什么状态？

第三部分：优先级排序

把目前关注的事情按高杠杆/中杠杆/低杠杆分类。

第四部分：未来六个月最大的机会

如果未来六个月只能抓住一个机会，最值得抓住的是什么？为什么？出现概率多大？如何提高成功率？

第五部分：未来六个月最大的风险

如果未来六个月没有达到预期，最可能是什么原因？按概率排序，结合真实行为模式。

第六部分：时间预算

设计一个现实可执行的每周时间分配方案（工作/学习/健康/社交/创作/休息占比）。

第七部分：预测

预测六个月后的：工作能力、技术能力、学习能力、身体状态、社交状态、财富状态、幸福感。基于数据推断，不要鼓励式回答。

最终结论

如果未来六个月我只能记住三件事，帮助我获得最大成长，是哪三件事。

输出要求

* 使用 Markdown 标题层级
* 包含时间线（Mermaid timeline 适合）
* 包含优先级矩阵
* 包含风险分析
* 包含具体行动项
* 包含季度里程碑
* 包含 Executive Summary

不要总结过去。
